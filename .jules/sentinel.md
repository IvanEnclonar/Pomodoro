## 2024-05-24 - Missing App Sandbox & Hardened Runtime in custom macOS build scripts
**Vulnerability:** The standalone `build.sh` script did not apply code signing with the `com.apple.security.app-sandbox` entitlement or the `--options runtime` flag. This left the built application running outside the macOS App Sandbox, allowing it unrestricted access to the user's filesystem and system resources, and disabled the Hardened Runtime protections against code injection and memory tampering.
**Learning:** When projects eschew Xcode for custom shell scripts to build macOS applications, crucial security features like ad-hoc code signing and entitlements are often omitted because they are not strictly required to produce a runnable executable. However, these are fundamental defense-in-depth mechanisms on macOS.
**Prevention:** Always verify that custom build scripts for macOS applications explicitly generate an entitlements file (enabling the App Sandbox at minimum) and invoke the `codesign` tool with the appropriate flags (`--options runtime`) before distributing or running the application bundle.
