## 2024-05-18 - Local DoS via Untrusted AppStorage Overflows
**Vulnerability:** Core arithmetic logic (durations, streak thresholds) directly used `@AppStorage` defaults without validation. Because UserDefaults can be manipulated externally, an excessively large integer injected into `focusDurationMinutes` or `streakMinMinutes` could cause an integer overflow during multiplication (e.g., `focusDurationMinutes * 60`), which safely traps and crashes Swift apps by default, leading to a local Denial of Service (DoS).
**Learning:** Values originating from UserDefaults (especially via SwiftUI's `@AppStorage`) must be treated as untrusted input. Unlike languages that wrap on overflow, Swift crashes on integer overflow to prevent undefined behavior, making unchecked external integers a direct crash risk.
**Prevention:** Always clamp or bounds-check untrusted input from `@AppStorage` (e.g., `max(1, min(1440, input))`) before using it in calculations, especially multiplications.
