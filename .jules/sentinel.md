## 2024-06-03 - Enable Default-Deny App Sandbox via codesign
**Vulnerability:** The macOS Pomodoro application was built using a custom bash script that did not apply codesigning, the Hardened Runtime, or the App Sandbox (`com.apple.security.app-sandbox`). This allowed the application to run with the full privileges of the user, posing a risk of privilege escalation or system compromise if an underlying vulnerability (such as an interaction with a malicious file) were exploited.
**Learning:** For macOS applications built outside of Xcode (e.g., via a shell script using `swiftc`), it is critical to manually generate an `entitlements.plist` file and pass it to the `codesign` tool. The `--options runtime` flag must also be passed to enforce Hardened Runtime execution.
**Prevention:** Always ensure standalone build scripts for macOS apps implement a `codesign` step using an `entitlements.plist` file, applying a default-deny App Sandbox configuration when no extra permissions are required.
