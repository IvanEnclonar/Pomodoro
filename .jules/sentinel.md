## 2026-03-11 - Integer Overflow DoS and Invalid Object Instantiation from UserDefaults Tampering
**Vulnerability:** Untrusted input from `@AppStorage` (UserDefaults) was being used directly in arithmetic operations (`totalDuration`, `currentStreak`) without bounds checking. Additionally, user-controlled strings were directly used to instantiate `NSSound` objects.
**Learning:** In Swift, integer overflows trap (crash) by default. Maliciously altering `UserDefaults` (e.g., via a `.plist` file) with excessively large values causes the application to crash on launch or during timer execution, leading to a local Denial of Service (DoS). Unvalidated string inputs for `NSSound` can also lead to resource misuse or application instability.
**Prevention:** Treat all values from `UserDefaults` (`@AppStorage`) as untrusted input. Clamp integer values to safe bounds before using them in arithmetic operations. Always validate string inputs against a known allowlist before instantiating objects or accessing resources.
