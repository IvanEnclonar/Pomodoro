## 2026-03-18 - Missing macOS App Sandbox in Ad-Hoc Build Script
**Vulnerability:** The standalone build script `build.sh` failed to codesign the application with the macOS App Sandbox (`com.apple.security.app-sandbox`) and Hardened Runtime (`--options runtime`) enabled. This left the compiled app with unrestricted access to the filesystem and user resources if a vulnerability were exploited, effectively bypassing standard macOS isolation protections.
**Learning:** For macOS applications built manually outside of Xcode using `swiftc`, entitlements must be explicitly defined in a `.plist` file and passed to the `codesign` tool. Failing to do this produces a default, unsandboxed binary. This is an architectural gap where simple scripts bypass default platform protections that Xcode usually enforces.
**Prevention:** Always require an explicit entitlements file defining the sandbox when scripting macOS application builds, and ensure `codesign` is invoked with `--options runtime` to enable Hardened Runtime alongside the sandbox.
